# Machine Learning-Based Early Prediction of Power and Timing for FPGA-Implemented Parameterized Array Multipliers

## Overview
This ongoing FPGA/VLSI project focuses on implementing parameterized array multipliers using Verilog HDL and AMD Vivado, with the broader goal of exploring machine-learning-based early prediction of FPGA power consumption and timing characteristics.

## Work Completed
- Implemented and simulated 2×2, 4×4, and 8×8 array multipliers using Verilog HDL.
- Completed physical implementation up to the 2×2 multiplier.
- Collected simulation outputs for verification and reference.

## Tools and Technologies
- Verilog HDL
- AMD Vivado
- FPGA Design
- Digital Logic Design
- RTL Simulation
- Machine Learning (prediction component under development)

## Repository Structure
- `2x2/` — Verilog source and related files for the 2×2 multiplier.
- `4x4/` — Verilog source and related files for the 4×4 multiplier.
- `8x8/` — Verilog source and related files for the 8×8 multiplier.
- `Output-Screenshots/` — Simulation output screenshots.

*Folder names may differ depending on the files uploaded.*

## Current Status
**In Progress.** Verilog implementation and functional simulation have been completed for the listed multiplier sizes. Physical implementation is completed up to 2×2. The machine-learning-based prediction approach is still under development.

## Objective
To investigate whether machine learning can help predict power consumption and timing characteristics of FPGA-implemented parameterized array multipliers at an early design stage.

## Note
This repository contains the source files and simulation outputs currently available for the project. Further implementation, analysis, and prediction-model development are ongoing.
